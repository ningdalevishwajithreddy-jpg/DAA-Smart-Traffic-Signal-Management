    Complexity notes

    Heap Dijkstra: time O((V+E) log V), space O(V+E) — the heap always hands over the smallest time. Array version: O(V²) — it scans every place each round. Bellman-Ford: O(V·E) — it rechecks every road many times; used only to double-check answers in tests.
